Narration maker

Reads the film's script aloud with a neural voice (Kokoro, Apache-2.0) that runs in this browser tab. Nothing is installed. The first run downloads the voice model (about 90 MB). Serve the project over http (for example python3 -m http.server) and open this page from there.

Listen first. When you like it, press and choose this project's narration folder (or use the per-line links). The film plays 01.wav, 02.wav, … automatically.
